# GZG 常见错误与修正

按“报错信息 → 原因 → 改法”排列。报错中的 `你是不是想写 'xxx'？` 通常就是答案。

## 语法错误（退出码 65）

| 报错 | 原因 | 改法 |
|---|---|---|
| `语句后面多了内容（一行写多条语句请用 ';' 分隔）` | 一行里写了两条语句；或在语句开头写了字典字面量 `{a: 1}` | 用 `;` 或换行分隔；字典放进 `let`/`return`/括号里 |
| `函数体需要以 '{' 开始（或使用 '=> 表达式'）` | 写了 Python 风格的 `def f():` 或 `fn f():` | `fn f() { ... }` |
| `这里需要 '{'` | `if x:` 或 `if (x) stmt` 省略了花括号 | `if x { ... }`，花括号不能省 |
| `变量 'x' 已在当前作用域中声明过` | 同一个块里 `let` 了两次 | 第二次去掉 `let`，直接赋值 |
| `不能给常量 'X' 重新赋值` | `const` 声明后又赋值 | 改用 `let` |
| `不能使用全角符号 '（'` | 中文输入法打出了全角标点 | 换成半角 `( ) , ; : "` |
| `赋值目标无效` | 如 `a + b = 1`、`f() = 1` | 只能给变量、字段、下标赋值 |
| `表达式形式的 match 不支持绑定变量` | `let r = match x { n if n > 0 => ... }` | 改成 `_ if x > 0 =>`，或用语句形式的 match |
| `for 循环的可迭代表达式较复杂时请用括号括起来` | `for x in cond ? a : b {` | `for x in (cond ? a : b) {` |
| `没有默认值的形参不能放在有默认值的形参之后` | `fn f(a = 1, b)` | 把有默认值的参数放到最后 |

## 运行错误（退出码 70）

| 报错 | 原因 | 改法 |
|---|---|---|
| `变量 'x' 未定义` | 拼写错误、忘了 `let`、或在定义前就调用了 | 先 `let x = ...`；检查拼写 |
| `变量 'x' 未定义，请先用 let 声明` | 直接 `x = 1` 而没有声明 | `let x = 1` |
| `不能把 string 和 int 相加` | `"a" + 1` | `"a{1}"` 或 `"a" + str(1)` |
| `array 类型没有方法 'append'，你是不是想写 'push'？` | 用了 Python/JS 的方法名 | 按提示改；方法表见 reference.md |
| `字典中没有键 "k"` | 读取不存在的键 | `m.get("k", 默认值)` 或先 `if m.has("k")` |
| `数组下标 5 越界（长度为 3）` | 下标超出范围 | 检查循环边界；`0..len(a)` 不含 `len(a)` |
| `Point 没有字段 'z'（结构体的字段在定义时确定）` | 给实例加了新字段 | 在 `struct` 里声明该字段（可给默认值） |
| `创建 Point 时缺少字段 'y'` | 构造时少了必填字段 | 传入该字段，或在定义里给默认值 `y = 0` |
| `函数 f 需要 2 个参数，实际传入 1 个` | 参数个数不符 | 补参数，或给参数设默认值 |
| `除数不能为 0` | `/`、`//`、`%` 的右边为 0 | 先判断 |
| `int 类型的值不能被调用` | 变量名覆盖了同名函数，如 `let len = 3` 后再调 `len(x)` | 换个变量名 |
| `调用层数超过 10000 层` | 无限递归或递归太深 | 检查终止条件，或改为循环 |
| `不能用 '<' 比较 string 和 int` | 混合类型比较 | 先 `int(s)` 转换 |
| `string 类型的值不支持下标赋值` / `字符串不可修改` | `s[0] = "x"` | 构造新串：`"x" + s[1:]` |
| `无法把字符串 'abc' 转换为整数` | `int()` 输入非法 | 用 `s.is_digit()` 先检查，或包在 `try` 里 |

## 不报错但结果不对

- **`match` 分支 `foo => ...` 总是命中**：单独的标识符是绑定，不比较。改成 `(foo) =>`。
- **`7 / 2` 得到 `3.5` 而不是 `3`**：整数除法用 `//`。
- **`print(a.sort())` 输出 `nil`**：`sort()` 原地排序返回 nil，要结果用 `a.sorted()`。
- **两个变量“同时变了”**：数组/字典/实例是引用，需要独立副本时用 `copy(x)`。
- **`write("a", "b")` 输出 `ab`**：`write` 不加空格，`print` 才用空格分隔。
- **交互程序在管道输入下死循环**：`input()` 在输入结束时返回 `nil`，要判断 `if line == nil { break }`。
- **大整数结果变成负数**：整数是 64 位，乘法溢出会回绕。需要时先取模。
